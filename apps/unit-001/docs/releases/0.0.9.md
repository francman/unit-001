# unit-001 0.0.9

The browser workspace now explains how to recover from an incorrect address: use its printed `http://127.0.0.1:PORT` URL and forward the same port through SSH. A rejected request receives the configured address rather than an untrusted, reflected hostname. Browser access checks, pairing and permissions remain unchanged.

Existing installations use their signed updater. Restart an existing `agent web` command after updating so its gateway uses the new code. The gateway still runs only on loopback; no public firewall opening is needed. See [browser access](../web-ui.md).

This patch changes diagnostics, not the mission model or stored state. Continuous purpose-driven planning remains unfinished. Release qualification includes the focused origin/security regressions, actual Chromium navigation and pairing, clean Linux packaging, signed publication verification, and the installed owner's health before and after activation. The complete 0.0.8 Ubuntu/systemd qualification remains the unchanged installer/updater baseline.
